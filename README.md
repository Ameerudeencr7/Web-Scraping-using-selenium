# Amazon Books Web Scraper (Selenium)

This project is a **web scraping tool built using Python and Selenium** to extract book details from Amazon.
The script automates browser actions to search for books and collect information such as **book title, price, and ratings**.
The scraped data is then stored in an **Excel file using OpenPyXL** for easy access and analysis.

## Features

* Automated browser interaction using **Selenium WebDriver**
* Scrapes **Amazon book search results**
* Extracts book **title, price, and rating**
* Saves scraped data into **Excel (.xlsx) file**

## Technologies Used

* Python
* Selenium
* OpenPyXL
* Chrome WebDriver

## Installation

1. Clone the repository

```
https://github.com/Ameerudeencr7/Web-Scraping-using-selenium.git
```

2. Navigate to the project folder

```
cd amazon-book-scraper
```

3. Install required libraries

```
pip install selenium openpyxl
```

4. Download and setup **ChromeDriver** compatible with your Chrome browser.

The script will:

1. Open the browser
2. Search books on Amazon
3. Extract book information
4. Save the data to an Excel file.

## Output

The scraped data will be saved in an **Excel file** containing:

* Book Title
* Price
* Rating
